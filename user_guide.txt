Руководство пользователя:

1. Загрузка данных:
   - Нажмите кнопку "Выбрать файл…" и выберите файл в формате TXT.
   - Первая строка файла должна содержать информацию о количестве признаков, количестве объектов (количестве кластеров - если есть)
   - Данные отобразятся в таблице "Загруженные данные".

2. Выбор признаков:
   - В разделе "Выбор признаков" отметьте чекбоксы для тех столбцов (признаков), которые хотите использовать в кластеризации. Признаков для кластеризации должно быть выбрано минимум 2.

3. Метод кластеризации:
   - Выберите метод: "KMeans" или "DC-алгоритм (LSA)" из выпадающего списка.

4. Параметры:
   - Укажите "Количество кластеров". Если оставить 0, количество будет определено автоматически.

5. Визуализация кластеров:
   - Нажмите кнопку "Визуализировать кластеры" для запуска процесса кластеризации.
   - Результаты (график и метрики) отобразятся в отдельном окне.

6. Загрузка эталонных данных:
   - Нажмите "Загрузить эталонные данные" для выбора файла с эталонными метками.
   - Эталон отобразится в таблице "Эталонные данные".
   - График сразу отобразится в окне "Результаты".


7. Очистка эталона:
   - Нажмите "Очистить эталон" для удаления загруженных эталонных данных.

8. Просмотр результатов:
   - Кнопка "Просмотр результатов" открывает окно с предыдущими результатами кластеризации.

9. Сохранение графиков:
   - В окне результатов нажмите "Сохранить графики" для экспорта в PNG графиков из окна "Результаты".

Программа предназначена для анализа кластеризации данных с использованием алгоритмов K-средних и DC (LSA).
Она позволяет визуализировать кластеры, рассчитывать метрики и сравнивать с эталоном.
